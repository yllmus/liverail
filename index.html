Attribution

Known coverage gaps — not hidden

PL and Germany's map positions are schedule-interpolated rather than GPS and only resolve for a minority of trains. Germany's live coverage skews toward DB Regio / S-Bahn service; long-distance ICE/IC visibility is limited. Route labels show a friendly line description next to the operator code where the source feed provides one — Poland's does for every route, Austria's for most. Germany's does not: gtfs.de's feeds carry no route description at all, so German routes show the raw code only (e.g. RE54).

Cancellations are shown for Poland and Germany, whose feeds report them. Hungary's and Austria's do not: MÁV's live endpoint only describes trains that are physically running, and ÖBB published none in our sampling — so for those two countries an absence of cancellations means "not reported", not "nothing cancelled". Platform numbers are shown wherever the source provides one, which is uneven by country: Hungary fills roughly 8 in 10, Austria about half, Germany fewer than 1 in 10, and Poland's feed carries no platform data at all.
